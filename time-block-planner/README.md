# 타임블록 자동 계획 프롬프트

## 도메인 맥락

나는 매일 반복되는 업무와 개인 일정을 관리하며, 할 일 정리와 타임블록 계획 수립을 자동화하고 싶습니다.

## 동작 분석

1. **분해**: 할일 목록, 소요 시간, 마감일, 가용 시간 블록, 집중도 요구치로 분리
2. **패턴**: 오전 고집중 배치, 90분 단위 블록 후 휴식, 마감 임박 작업 최우선
3. **추상화**: 가용 시간 대비 핵심 Top 3 작업을 타임블록으로 구조화
4. **알고리즘**: 할일 입력 → 우선순위 계산 → 시간 분할 → 타임라인 배치 → 일정표 출력

## 출력 요구

시간대별(오전/오후/저녁) 타임블록 실행 계획표 형식으로, 한국어로 작성.

## 검증 기준

내가 봤을 때 **"고민 없이 바로 첫 작업에 착수할 수 있는 현실적인 일정인가"**로 평가할 것.
